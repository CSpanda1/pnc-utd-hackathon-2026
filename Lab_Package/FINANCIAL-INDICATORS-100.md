# 100 Financial Indicators Reference

This document explains all 100 portfolio-level indicators generated by:

```bash
python review_financial_indicators.py
```

These are **cross-customer aggregate indicators** computed from synthetic workshop data. They are for education and analysis, not underwriting or financial advice.

## Indicator structure

The script generates:

1. **80 distribution indicators** = 10 base customer metrics × 8 distribution stats.
2. **20 portfolio indicators** = shares/ratios/count-based aggregate metrics across customers.

Total: **100 indicators**.

## Distribution indicator naming pattern (80 total)

Pattern:

```text
<base_metric>_<stat>
```

Where `<stat>` is one of:

| Suffix | Meaning |
|---|---|
| `_mean` | Arithmetic average across reviewed customers |
| `_median` | Median across reviewed customers |
| `_min` | Minimum observed value |
| `_max` | Maximum observed value |
| `_p10` | 10th percentile (linear interpolation) |
| `_p25` | 25th percentile (linear interpolation) |
| `_p75` | 75th percentile (linear interpolation) |
| `_p90` | 90th percentile (linear interpolation) |

### Base customer metrics used for distribution indicators

| Base metric | Customer-level source definition |
|---|---|
| `monthly_income` | Synthetic monthly household income |
| `monthly_non_debt_expenses` | Synthetic non-debt monthly expenses |
| `monthly_debt_payments` | Sum of scheduled debt payments |
| `monthly_cash_surplus` | `monthly_income - monthly_non_debt_expenses - monthly_debt_payments` |
| `liquid_assets` | Checking + savings balances |
| `emergency_fund_months` | `liquid_assets / (monthly_non_debt_expenses + monthly_debt_payments)` |
| `debt_payment_to_income_pct` | `100 * monthly_debt_payments / monthly_income` |
| `credit_card_utilization_pct` | `100 * credit_card_balance / credit_limit` |
| `savings_rate_pct` | `100 * monthly_cash_surplus / monthly_income` |
| `liquid_assets_to_debt_pct` | `100 * liquid_assets / total_debt_balances` |

## Portfolio aggregate indicators (20 total)

| Indicator | Definition |
|---|---|
| `customer_count_reviewed` | Number of customers included in aggregation |
| `pct_negative_monthly_surplus` | % customers with `monthly_cash_surplus < 0` |
| `pct_positive_monthly_surplus` | % customers with `monthly_cash_surplus > 0` |
| `pct_emergency_fund_lt1_month` | % customers with `emergency_fund_months < 1` |
| `pct_emergency_fund_lt3_months` | % customers with `emergency_fund_months < 3` |
| `pct_high_dti_gt40` | % customers with `debt_payment_to_income_pct > 40` |
| `pct_high_card_util_gt70` | % customers with `credit_card_utilization_pct > 70` |
| `pct_negative_savings_rate` | % customers with `savings_rate_pct < 0` |
| `pct_positive_net_worth_partial` | % customers with `net_worth_partial > 0` |
| `pct_customers_with_external_transfers` | % customers with non-zero external transfer totals in synthetic history |
| `avg_transaction_count_per_customer` | Mean monthly-history transaction count per customer |
| `median_transaction_count_per_customer` | Median monthly-history transaction count per customer |
| `avg_spending_to_income_history_ratio` | Mean of `spending / paycheck_income` over customers (history totals) |
| `median_spending_to_income_history_ratio` | Median of `spending / paycheck_income` over customers |
| `avg_debt_interest_share_of_spending` | Mean of `debt_interest / spending` over customers |
| `median_debt_interest_share_of_spending` | Median of `debt_interest / spending` over customers |
| `avg_external_transfer_dependency_ratio` | Mean of `(external_in + external_out) / paycheck_income` over customers |
| `median_external_transfer_dependency_ratio` | Median of `(external_in + external_out) / paycheck_income` over customers |
| `avg_fees_to_income_ratio` | Mean of `fees / paycheck_income` over customers |
| `median_fees_to_income_ratio` | Median of `fees / paycheck_income` over customers |

## Interpretation notes

- All values come from synthetic data and synthetic transaction history.
- Percentages are in percentage points unless noted as ratio.
- Ratio fields can exceed 1.0 when numerator is larger than denominator.
- External-transfer metrics describe calibration flows used in synthetic generation, not observed real-world account behavior.
